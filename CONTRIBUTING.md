# Contributing

Contributions are welcome after the repository opens for public collaboration. Please keep changes within authorized, reproducible security research and do not submit live credentials, private approval records, customer data, or exploit output from systems you do not own or have permission to assess.

Before proposing a change, run the local tests relevant to the modified files and explain what was actually verified. A passing synthetic test does not establish live effectiveness. New adapters should preserve scope, action admission, budget, stop, credential, and evidence-custody boundaries.

Report vulnerabilities through the private channel described in [SECURITY.md](SECURITY.md), not in a public issue.
