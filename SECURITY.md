# Security Policy

## Reporting Vulnerabilities

After public release, please use the repository's private vulnerability reporting feature to contact the maintainers. Do not include credentials, personal data, or live target data in a public issue or pull request. If the reporting feature is unavailable, request a private contact channel without disclosing vulnerability details publicly.

## Assessment Authorization

This project is intended for authorized security assessments. A repository license, example configuration, or test fixture does not authorize access to any target. Live use requires current owner permission and the controls described in the [Safety Boundary Reference](docs/safety-boundary-reference.md).

## Support Status

The 0.1.0 release line is an early development version. It is not a production qualification or a promise of deployment support. Security fixes will be documented through the repository's normal release process once public release begins.
