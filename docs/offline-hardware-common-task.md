# Offline Hardware Common Task

The supplied I2C write-frame, flash region-map, and smartcard file-access
specialists can work inside one synthetic R0 task. The composer retains three
separate original models, specialist profiles, and the existing
`AOE-GD-D18-CMD` commander reference. Grouping does not assert that the
declarations describe one device, chip, card, bus, operator, or target.

The integration test checks independent ownership entries, original-model
replay, and no operational effects. A late resource grant or an invalid
synthetic model blocks task publication. The common task is not hardware
access, human approval, a verified finding, qualification, or permission for
live assessment.
