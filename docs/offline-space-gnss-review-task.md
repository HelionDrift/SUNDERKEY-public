# Supplied Space and GNSS Header Review Common Task

The checked common task joins GD-D25-S08 CCSDS Space Packet primary-header
geometry and GD-D25-S09 RINEX observation-header declarations as distinct
specialist jobs. The independent synthetic fixtures do not establish one
mission, spacecraft, station, or time interval. The task preserves both
original requests and commander ownership, requires R0 and empty resources,
and verifies the report against the separate original task.

The collaboration does not authenticate a source, parse mission data,
validate GNSS measurements, contact a target, publish a finding, or grant
action authority or qualification.
