# Supplied Oracle Enterprise Grant Policy

The GC-D16-S05 partial component compares synthetic opaque grant triples with
a supplied policy for the Oracle enterprise specialist lane. Its checked
example is [`examples/offline-oracle-enterprise-grants-component.json`](../examples/offline-oracle-enterprise-grants-component.json).

No EBS, PeopleSoft, WebLogic, account, credential, or network is accessed.
The model does not parse product-native roles or establish effective access.
A mismatch is not proof of exploitation. The result is nonqualifying R0
evidence and grants no authority.
