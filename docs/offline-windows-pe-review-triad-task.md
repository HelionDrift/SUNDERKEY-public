# Supplied Windows PE Review Triad Common Task

The checked common task joins GB-D08-S15 PE32+ layout review,
GE-D21-S01 section-permission policy, and GE-D21-S03 driver-marker
projection as three distinct specialist jobs. Their checked fixtures
are independent synthetic PE records, not evidence that the same
binary was reviewed three times. The task preserves each original
request and commander, requires R0 and empty resources, and verifies
the combined report against the separate original task.

The collaboration produces only bounded static descriptions. It
does not authenticate a source, load a driver, confirm runtime
permissions, demonstrate exploitability, publish a finding, or grant
action authority or qualification.
