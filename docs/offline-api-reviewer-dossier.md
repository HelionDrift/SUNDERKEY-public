# Offline API reviewer dossier

The dossier is a nonfinding index for a human reviewer. It reproduces the
proposal-only review and planning bridge and the replay-aware retest
transition, then requires their prior case, result, batch, scope, and tenant
bindings to agree.

It contains immutable digests and case IDs, the observation-change label,
proposed task IDs, and the child world snapshot digest. It does not include
raw response bodies or create a validated finding. Review remains pending,
finding count is zero, and remediation and report publication are not claimed.

An actual assessment report still requires independently verified evidence,
review decisions, live-current authority where positive use is involved, and
accountable report attestation. This dossier cannot satisfy those gates.
