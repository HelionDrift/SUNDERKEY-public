# Supplied iOS Instrumentation Trace Policy

The GB-D08-S06 partial component compares synthetic, content-free trace-state
transitions with a supplied test policy. Its checked example is
[`examples/offline-ios-instrumentation-trace-component.json`](../examples/offline-ios-instrumentation-trace-component.json).

No iOS device or app is connected and no instrumentation is run. The model
accepts no hook, binary, payload, or device command. Declared states and
completeness are assertions, not runtime evidence. This is nonqualifying R0
evidence and grants no authority.
