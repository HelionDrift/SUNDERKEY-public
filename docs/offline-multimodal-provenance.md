# Supplied Multimodal Provenance Claims

The GD-D20-S17 partial component compares synthetic source-digest labels and
transformation disclosures with supplied media authenticity claims. Its
checked example is [`examples/offline-multimodal-provenance-component.json`](../examples/offline-multimodal-provenance-component.json).

No media bytes are decoded, no signature is verified, and no deepfake is
detected. Digest labels, claims, and completeness are assertions. A flagged
metadata inconsistency is not proof of manipulation or impact. This is
nonqualifying R0 evidence and grants no authority.
