# Offline Unix Policy Common Task

One synthetic task combines nine source-bound Linux, macOS, BSD, and Unix
projections:
eBPF helper policy, shell-tool approvals, logging routes, privileged-item
write and execution declarations, TCC/SIP/Gatekeeper state, launch-job
approval, Keychain and iCloud access, IPC clients, and Unix IPC permissions.
Each job
retains its original model, specialist profile, commander ownership, and
content-addressed result. The common-task test verifies replay and rejects
a late network grant before dispatch.

The task does not connect to a kernel or host, load programs, execute commands,
read logs or credentials, alter controls, establish a vulnerability, publish
findings, or qualify an expert. Every result is an unsigned, nonqualifying
partial projection.
