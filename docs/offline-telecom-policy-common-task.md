# Offline Telecom Policy Common Task

Six GC-D13 specialists can share one synthetic task while retaining distinct
source models, profile ownership, the existing domain commander, and the
independent validator. The [common-task test](../tests/agents/test_offline_telecom_policy_common_task_integration.py)
replays the original task and rejects a late network grant or nonsynthetic
input before dispatch.

The appliance, RF, mobile-core, signaling, Open RAN, and eSIM projections are
bounded declaration comparisons. They do not contact a network, radio,
subscriber, RIC, appliance, or provisioning service. No packet is sent and no
profile or policy is changed. The six reports remain unsigned, nonqualifying
partial A7.4 evidence and grant no live authority.
