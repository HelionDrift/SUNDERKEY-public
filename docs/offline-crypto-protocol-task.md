# Offline Crypto Protocol Common Task

The protocol-state, RNG-sample, E2EE-epoch, and custom-framing specialists can work within one
R0 synthetic task under `AOE-GE-D22-CMD`. The composer retains the separate
original models for `AOE-GE-D22-S01`, `AOE-GE-D22-S08`, `AOE-GE-D22-S13`,
and `AOE-GE-D22-S12`.
Their reports are not assumed to describe the same protocol, key, deployment,
user population, or target.

The integration test checks all four ownership entries, original-model replay,
and the common no-effect boundary. A late network resource grant or invalid
framing hypothesis prevents publication of the whole task. No component authorizes
another, and the commander reference does not represent a human approval,
cryptographic finding, qualified specialist, or live assessment.
