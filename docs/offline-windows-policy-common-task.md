# Offline Windows Policy Common Task

One synthetic task combines GC-D11-S08 privilege-artifact, GC-D11-S09
autostart, GC-D11-S10 administration-invocation, GC-D11-S11 protected-material,
GC-D11-S12 remote-route, and GC-D11-S13 security-control projections.
Each job retains its separate original model, profile ownership, commander,
and content-addressed result. The common-task test verifies replay and rejects
a late network grant before dispatch.

The task does not inspect a Windows host, parse or execute commands, read
credentials, establish a vulnerability, publish findings, or qualify an
expert. Every result remains an unsigned, nonqualifying partial projection.

See the [integration test](../tests/agents/test_offline_windows_policy_common_task_integration.py)
and the six linked component guides in the
[specialist index](offline-specialist-wave-components.md).
