# Offline Protocol Review Common Task

The custom-framing and protocol-trace specialists can work within one R0
synthetic task under their separate `AOE-GE-D22-CMD` and `AOE-GC-D13-CMD`
commander references. The composer retains two separate original models. It
does not infer that a framing hypothesis and trace set describe the same
implementation, packet, deployment, or target.

The integration test checks both ownership entries, original-model replay,
and the common no-effect boundary. A late network grant or invalid trace
prevents publication of the entire task. Neither commander reference is human
approval, a verified vulnerability, specialist qualification, or permission
for live testing.
