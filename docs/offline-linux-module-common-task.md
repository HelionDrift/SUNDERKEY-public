# Supplied Linux Module Review Common Task

The checked common task joins GB-D08-S17 ELF64 layout review and GE-D21-S04
`.modinfo` tag projection as distinct specialist jobs. Their checked
fixtures are independent synthetic ELF records, not proof that the same
binary was reviewed twice. The task preserves both original requests and
commander assignments, requires R0 and empty resources, and verifies the
combined report against the separate original task.

The collaboration produces only bounded static descriptions. It does not
authenticate a source, load a module, confirm runtime behavior, demonstrate
exploitability, publish a finding, or grant action authority or qualification.
