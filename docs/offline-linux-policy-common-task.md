# Offline Linux Policy Common Task

The supplied sudo grant, namespace/cgroup, and scheduled-artifact specialists
can work in one synthetic R0 task. The composer preserves their separate
original models, specialist profiles, and the existing `AOE-GC-D12-CMD`
commander reference. Grouping does not assert that the declarations describe
one host, tenant, operator, or target.

The integration test checks three independent ownership entries, original-
model replay, and no operational effects. A late process-resource grant or an
invalid synthetic model blocks task publication. The common task is not host
inspection, command execution, human approval, a verified finding,
qualification, or permission for live assessment.
