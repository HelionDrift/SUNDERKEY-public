# Supplied Mobile-Core Relations

The GC-D13-S11 partial component compares synthetic opaque mobile-core
function relationships with supplied allowed edges. Its checked example is
[`examples/offline-mobile-core-component.json`](../examples/offline-mobile-core-component.json).

This does not contact a mobile network, authenticate a function, send packets,
or establish actual control-plane reachability. Supplied edges and completeness
remain assertions. A mismatch is not proof of exploitation or impact. The
result is nonqualifying R0 evidence and grants no authority.
