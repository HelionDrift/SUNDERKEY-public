# Supplied Hardware Structure and Cache Common Task

The checked common task joins GD-D18-S11 cache-set projection and
GD-D18-S12 Yosys-style netlist structural comparison as distinct
specialist jobs. Their fixtures are independent synthetic records, not
evidence that a cache trace belongs to the supplied design. The task
preserves both original requests and commander ownership, requires R0
and empty resources, and verifies the combined report against the
separate original task.

The collaboration does not authenticate a source, measure a cache,
simulate a design, infer leakage, detect a hardware trojan, publish a
finding, or grant action authority or qualification.
