# Offline Mobile and Model-Safety Common Task

Four GB-D08 mobile and two GD-D20 model-safety specialists can share one
synthetic task while keeping their separate original models, domain
commanders, and independent validators. The [common-task test](../tests/agents/test_offline_mobile_model_common_task_integration.py)
replays the original task and rejects a late network grant or nonsynthetic
input before dispatch.

The reports are content-free declaration projections. No device, app, model,
provider, media source, credential, or network is contacted. The task does not
run instrumentation, attempt root or jailbreak, submit prompts, inspect
media, detect deepfakes, or qualify candidates. It grants no live authority.
