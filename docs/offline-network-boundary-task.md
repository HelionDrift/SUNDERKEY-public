# Offline Network Boundary Task

The existing common-task composer can retain separate synthetic source models
for the `AOE-GC-D13-S04` switch VLAN projection, the `AOE-GC-D13-S05`
firewall rule-order projection, the `AOE-GC-D13-S07` NAC admission projection,
and the `AOE-GC-D13-S08` Wi-Fi policy projection. The
[`test_offline_network_boundary_task_integration.py`](../tests/agents/test_offline_network_boundary_task_integration.py)
test verifies four distinct profile and component owners under the existing
`AOE-GC-D13-CMD` commander, source-bound replay, no operational effects, and
pre-dispatch rejection of a late network resource grant.

Grouping these reports does not connect a VLAN to a firewall zone or NAC port,
infer that the models describe one network, verify chronology, prove a path, or
authorize a live action. Any relationship requires a separate declared,
reviewed evidence binding. All four reports remain unsigned, R0, and
nonqualifying.
