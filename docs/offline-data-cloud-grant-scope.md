# Offline Data-Cloud Grant Scope

This R0 component supports a narrow part of `AOE-GC-D14-S21`. It compares caller-supplied dataset classification and external-sharing policy with active recipient-scope grants. A review candidate requires complete context and a prohibited external or public grant, or a public grant to a restricted dataset.

The component does not query a data-cloud provider, resolve inherited roles, or access data. Classification, policy, and grant scope are caller-supplied labels. A mismatch does not prove effective access or disclosure.

The unsigned report requires separately retained original-model replay and grants no finding, qualification, or positive-use authority.
