# Offline Legacy Grant Common Task

Five GC-D16 specialists can share one synthetic task while retaining distinct
original models, profile ownership, the existing domain commander, and the
independent validator. The [common-task test](../tests/agents/test_offline_legacy_grant_common_task_integration.py)
replays the original task and rejects a late network grant or nonsynthetic
input before dispatch.

The z/OS, IBM i, enterprise Unix, SAP, and Oracle projections compare only
opaque grant declarations with supplied policy. They do not parse native
authorization sources, authenticate a principal, contact a platform, or
establish effective access. The results remain unsigned, nonqualifying
partial A7.4 evidence and grant no live authority.
