# Supplied Graph and Path Review Common Task

The checked common task joins GA-D01-S11 abstract graph reachability
and GA-D04-S09 review-checkpoint coverage on one synthetic exercise
record. The first job assesses supplied reachability; the second asks
whether declared routes can avoid named review checkpoints. Each job
retains its original request and commander ownership. The task enforces
R0, empty resources, and separate original-model replay.

The two projections are related but not independent proof of a real
path. The common task does not resolve a target, verify review
authority, execute a route, publish a finding, or qualify an agent.
